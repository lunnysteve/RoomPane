# Project Documentation: home-display

## 📌 Description & Purpose
**home-display** is a smart wall display dashboard system running on FullPageOS and served via Caddy on LXC 105 (`192.168.0.21`). It provides rotating full-screen web pages including large weather dashboards, ISS tracker, NASA astronomy pictures, countdown timers, and admin controls.
